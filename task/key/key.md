## Thuật ngữ kỹ thuật

| Thuật ngữ                      | Giải thích                                                                     |
| ------------------------------ | ------------------------------------------------------------------------------ |
| Cold Start                     | Bài toán khởi động nguội — người dùng mới chưa có dữ liệu tương tác            |
| Cross-Validation               | Kỹ thuật kiểm định chéo — chia dữ liệu thành K phần để đánh giá mô hình        |
| Distributed Lock               | Khoá phân tán — cơ chế ngăn chặn truy cập đồng thời từ nhiều service           |
| Diversity Reranking            | Sắp xếp lại kết quả để đảm bảo tính đa dạng địa điểm                           |
| Event-Driven Architecture      | Kiến trúc hướng sự kiện — các service giao tiếp qua message queue              |
| Fingerprint-based Invalidation | Cơ chế vô hiệu hoá cache dựa trên vân tay của tương tác mới nhất               |
| Function Calling               | Kỹ thuật LLM trích xuất tham số có cấu trúc từ ngôn ngữ tự nhiên               |
| GridSearchCV                   | Tìm kiếm lưới siêu tham số với kiểm định chéo                                  |
| Hybrid Search                  | Tìm kiếm hỗn hợp — kết hợp SQL filter (cứng) với vector similarity (mềm)       |
| Latent Factors                 | Các yếu tố tiềm ẩn — đặc trưng ẩn được SVD phát hiện từ ma trận user-item      |
| Matrix Factorization           | Phân rã ma trận — kỹ thuật chia ma trận lớn thành các ma trận con              |
| Microservices                  | Kiến trúc vi dịch vụ — tách hệ thống thành nhiều service độc lập               |
| Monorepo                       | Kho mã nguồn đơn — nhiều dự án trong một repository                            |
| Outbox Pattern                 | Mẫu hộp thư đi — đảm bảo tính nhất quán dữ liệu qua Kafka                      |
| Precision@5                    | Tỷ lệ kết quả liên quan trong 5 kết quả đầu tiên                               |
| Recall@5                       | Tỷ lệ kết quả liên quan được tìm thấy trong 5 kết quả đầu tiên                 |
| Session-Aware Caching          | Cache nhận biết phiên — key cache bao gồm ý định và fingerprint của người dùng |
| Session Intent Detection       | Phát hiện ý định phiên — xác định đích đến người dùng đang quan tâm            |
| Time Decay                     | Suy giảm theo thời gian — tương tác cũ có trọng số thấp hơn tương tác mới      |
| Vector Embedding               | Nhúng vector — chuyển đổi văn bản/hình ảnh thành vector số học                 |
| Weighted Recency               | Gần đây có trọng số — ưu tiên tương tác mới nhất với trọng số cao hơn          |

## Bổ sung vị trí đặt tài liệu tham khảo trong luận văn

Theo chuẩn IEEE và quy định luận văn, **tài liệu tham khảo** được đặt ở vị trí:

1. **Ngay sau phần Kết luận (Chương 5)** — là phần cuối cùng trước Phụ lục
2. **Không đặt trong Phụ lục** — Phụ lục chỉ chứa dữ liệu bổ sung, mã nguồn, sơ đồ chi tiết
3. **Thứ tự trong luận văn:**

   ```
   Chương 1 → Chương 2 → ... → Chương 5 (Kết luận)
   → TÀI LIỆU THAM KHẢO (task/references/ref.md)
   → PHỤ LỤC (task/key/key.md và các phụ lục khác)
   ```

4. **Trong văn bản**, tham khảo được trích dẫn bằng số trong ngoặc vuông, ví dụ: `Koren et al. [12] đã chứng minh...`
5. **Mỗi nguồn chỉ đánh số một lần**, đánh số theo thứ tự xuất hiện lần đầu trong văn bản
6. **Tham khảo [1]–[8]** (website/documentation) dùng cho phần giới thiệu công nghệ
7. **Tham khảo [9]–[15]** (journal/conference) dùng cho phần lý thuyết thuật toán và phương pháp đánh giá
