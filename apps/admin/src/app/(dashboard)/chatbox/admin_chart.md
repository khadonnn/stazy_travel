## Chart nào sẽ xuất hiện sau fix?

Bấm các nút **được khoanh đỏ** trong chatbox admin (phần gợi ý bên cạnh input):

### 📊 Nhóm "Phân tích" — bấm các nút này:

| Nút bấm                   | Chart hiển thị               |
| ------------------------- | ---------------------------- |
| **💰 Doanh thu hôm nay**  | 📈 **Line Chart**            |
| **🔮 Dự báo 3 ngày tới**  | 🟦 **Area Chart** (forecast) |
| **⏰ Khung giờ cao điểm** | 📊 **Bar Chart**             |
| **📈 Xu hướng tuần này**  | 📈 **Line Chart**            |
| **🔍 Phân tích 30 ngày**  | 📈 **Line Chart**            |
| **📊 So sánh tuần**       | 📈 **Line Chart**            |
| **🚨 Quét bất thường**    | 📈 **Line Chart + Insight**  |

### 🏨 Nhóm "Khách sạn"

| Nút bấm                   | Chart hiển thị                 |
| ------------------------- | ------------------------------ |
| **🏨 Thống kê khách sạn** | 📊 **Bar Chart + KPI + Table** |
| **📊 Phân bố loại phòng** | 📊 **Bar Chart**               |

### 👥 Nhóm "Khách hàng"

| Nút bấm                    | Chart hiển thị                          |
| -------------------------- | --------------------------------------- |
| **👥 Người dùng truy cập** | 📊 **Horizontal Bar Chart** (Top Users) |
| **⭐ Top khách VIP**       | 📊 **Horizontal Bar Chart**             |

### Hoặc gõ trực tiếp các câu này:

| Gõ câu này                           | Chart hiển thị              |
| ------------------------------------ | --------------------------- |
| "Phân khúc khách hàng mới và cũ"     | 🍩 **Donut Chart**          |
| "Top 5 khách sạn nhiều booking nhất" | 📊 **Horizontal Bar Chart** |
| "Dự báo doanh thu 7 ngày tới"        | 🟦 **Area Chart**           |
