# Đã fix Recommendations không hiển thị + Giải thích evaluate.py vs evaluate_real.py

## Fix: Recommendations không hiển thị

**Nguyên nhân gốc:** Search-service trả về hotel IDs từ `__homeStay.json` (mock data) nhưng PostgreSQL có hotel IDs khác → `prisma.hotel.findMany({ where: { id: { in: candidateIds } } })` trả về rỗng.

**Đã fix:** Thêm Prisma fallback chain:

1. Thử fetch từ candidate IDs (search-service)
2. Nếu rỗng → fallback top-rated APPROVED hotels từ Prisma
3. Nếu có session destination → ưu tiên khách sạn ở destination đó
4. Nếu vẫn rỗng → lấy tất cả APPROVED hotels

**Đồng thời fix:** TypeScript errors do Prisma enum `InteractionType` chỉ có `VIEW`, `ADD_TO_WISHLIST`, `BOOK`, `CLICK_BOOK_NOW`, `CANCEL` (không có `LIKE`, `RATING`, `RATE_POSITIVE`, `RATE_NEGATIVE`). Đã dùng `where: { userId }` thay vì filter theo type.

## Phân biệt evaluate.py vs evaluate_real.py

### `evaluate.py` = Kiểm thử trên MOCK DATA (Controlled Synthetic)

- **Dữ liệu:** `__interactions.json` + `__reviews.json` (generated by `generate_mock_interactions.py`)
- **Mục đích:** Kiểm tra thuật toán trên dữ liệu **chuẩn, có kiểm soát, có ground truth**
- **Ưu điểm:** Reproducible, biết trước pattern, debug dễ
- **Chạy khi:** Muốn verify thuật toán hoạt động đúng logic trước khi test trên dữ liệu thật
- **Thứ tự chạy:**
  ```
  cd apps/search-service
  uv run python generate_mock_interactions.py  # Tạo mock data
  uv run python evaluate.py --mode all         # Kiểm thử trên mock
  ```

### `evaluate_real.py` = Kiểm thử trên DỮ LIỆU THẬT (PostgreSQL)

- **Dữ liệu:** Đọc trực tiếp từ PostgreSQL (`interactions` + `reviews` tables)
- **Mục đích:** Đánh giá hiệu quả thực tế trên dữ liệu người dùng thật
- **Ưu điểm:** Kết quả phản ánh đúng performance production
- **Chạy khi:** Đã có dữ liệu thật trong DB, muốn đo lường metrics thực tế
- **Thứ tự chạy:**
  ```
  cd apps/search-service
  uv run python train_real.py                    # Train SVD từ dữ liệu thật
  uv run python evaluate_real.py --mode all      # Đánh giá trên dữ liệu thật
  ```

### Thứ tự đúng trong quy trình đánh giá:

```
BƯỚC 1: Mock data evaluation (evaluate.py)
├── generate_mock_interactions.py → tạo __interactions.json
├── evaluate.py --mode implicit → Precision@5, Recall@5, NDCG@5
├── evaluate.py --mode explicit → RMSE, MAE
└── → Kiểm tra thuật toán có chạy đúng không

BƯỚC 2: Train SVD trên dữ liệu thật (train_real.py)
├── Đọc PostgreSQL interactions + reviews
├── Train SVD với cross-validation
└── → Lưu recsys_model.pkl

BƯỚC 3: Real data evaluation (evaluate_real.py)
├── evaluate_real.py --mode svd → RMSE, MAE trên test set
├── evaluate_real.py --mode implicit → Precision@5, NDCG@5
├── evaluate_real.py --mode explicit → RMSE, MAE rating prediction
└── → Kết quả đánh giá cho báo cáo
```

### Bảng kết quả sau khi chạy:

**Bảng 1: SVD Model** (chạy: `uv run python train_real.py` + `uv run python evaluate_real.py --mode svd`)

- Kết quả lưu tại: `analytics/real_svd_evaluation_report.json`

**Bảng 2: Implicit CF** (chạy: `uv run python evaluate_real.py --mode implicit`)

- Kết quả lưu tại: `analytics/real_implicit_cf_report.json`

**Bảng 3: Explicit CF** (chạy: `uv run python evaluate_real.py --mode explicit`)

- Kết quả lưu tại: `analytics/real_explicit_cf_report.json`

**Tất cả metrics tự động lưu vào SystemMetric table trong PostgreSQL** và hiển thị trên admin dashboard.
